2.2.0 Latest Release November 2026 · Windows, Linux, Android, Web

Eva 2.2.0 — A More Refined Experience

A major UI/UX redesign and frontend experience upgrade. Replaces the cramped desktop settings popup with a dedicated, spacious full-screen section, introduces smooth section navigation with animated tab indicators, establishes a consistent layout system, refines mobile touch interactions, and enforces strict desktop-only separation for local AI inference.

✦ Full-Screen Desktop Settings Experience
Settings on desktop and laptop layouts now expands into a dedicated full-screen application section with a grouped two-column navigation hierarchy, generous typography, and spacious card layouts.
✦ Refined Mobile Settings Presentation
Mobile settings preserves its familiar bottom-sheet dialog format with horizontal scrolling pill tabs, comfortable 44px+ touch targets, zero horizontal overflow, and safe-area padding.
✦ Fluid Motion & Interaction Animations
Added smooth Framer Motion tab transitions, active navigation pill gliding, search bar focus glow, button press feedback (0.97 scale), and accessible reduced-motion support.
✦ Consistent Layout & Symmetrical Cards
Eliminated awkward blank areas and disproportionate containers with balanced two-column and three-column grids, aligned top edges, and consistent radii.
✦ Desktop-Only Local AI Provider Separation
Local models (Ollama, LM Studio) are strictly reserved for Eva Desktop, preventing nonfunctional loopback errors on mobile while preserving cross-device settings integrity.
2.1.0 November 2026 · Windows, Linux, Android, Web

Astra Redesign, Dynamic Theme-Aware Icons & Setup Guide

A complete visual and architectural redesign. Rebuilt both the public product website and the web application from the ground up on the Astra 60-30-10 design system, introduced multi-platform dynamic theme-aware application icons, and created an interactive provider-aware onboarding experience.

✦ Complete Website & App Redesign
Recreated the public landing page with editorial product design, interactive studio switcher, live theme switcher, and 8 curated accent palettes. Upgraded the React web app across all three modes (Chatbot, Anime, World).
✦ Dynamic Theme-Aware App Icons
Android VectorDrawable adaptive launcher icons switch automatically between dark and light mode, with Android 13+ Material You monochrome support. Desktop Electron dynamically switches window/dock icons at runtime without restart.
✦ Astra 60-30-10 Color System
Astra Warm Dark (#12100E primary background, warm ivory text) and bright, pure minimal light (#FAFAFA pure neutral background, zero beige tint) with 8 independent curated palettes and WCAG AA contrast.
✦ Dynamic First-Launch Setup Guide
Provider-aware dynamic onboarding with verified documentation, live endpoint connection tests, copyable terminal snippets, and error troubleshooting for Groq, OpenRouter, Ollama, LM Studio, and OpenAI.

2.0.0 Major Architecture November 2026 · Windows, Linux, Android, Web

Rebrand to Eva, Hardware Security & AI Generator

Nexus rebranded to Eva. Introduced multi-provider engine, platform-native hardware security and credential protection, AI character generation with single-section regeneration, and native Android production packaging.

✦ Privacy-First Local Architecture
Zero telemetry, local client-side persistence, and zero central servers. All conversations and character lore remain strictly on your local device.
✦ Hardware Keystore Security
Platform-specific credential management: Electron safeStorage (OS Keychain/libsecret/DPAPI) and Android native Keystore plugin with AES-256-GCM.
✦ AI Character Profile Generator
Structured 12-dimension character creation from short natural language prompts, with section-by-section regeneration capabilities.
✦ 3-Way Conflict Merging
Intelligent field-level merging for characters, worlds, and messages. Concurrent edits preserve branched conflict copies rather than overwriting history.
